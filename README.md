# 🕐 Alba Manager

알바 근무시간을 기록하고 관리하기 위한 웹 서비스입니다.

직원은 자신의 근무시간을 등록하고 월별 근무시간을 확인할 수 있으며, 사장님은 등록된 직원들의 근무시간을 관리하고 확인할 수 있습니다.

## 🗄️ 데이터 모델

현재 설계 예정인 주요 엔티티입니다.

```text
User
 │
 ├── StoreMember
 │       │
 │       └── Store
 │              │
 │              └── WorkRecord
 │
 └── WorkRecord
```

### User

사용자 계정 및 권한을 관리합니다.

```text
id
email
password
name
role
```

### Store

알바생이 근무하는 매장을 관리합니다.

```text
id
name
```

### StoreMember

사용자와 매장의 관계를 관리합니다.

```text
id
user_id
store_id
role
```

### WorkRecord

사용자의 근무기록을 관리합니다.

```text
id
user_id
store_id
work_date
start_time
end_time
```
